# 实验目录

围绕仓库中 S-Mamba（#6）、GPS-Mamba（#10）等论文提出的"Mamba 的跨变量相关性建模还能怎么改进"所做的验证实验。

| 目录 | 内容 | 主要结论 |
|---|---|---|
| [`hub_ssm/`](hub_ssm/README.md) | 合成数据（64 个变量，簇 + 时滞结构）：与顺序无关的枢纽混合器 Hub-SSM、稀疏 top-k 项、低秩 + 稀疏 | 枢纽混合器精度不足；稀疏项在合成数据上大幅优于全注意力，低秩分支没有额外贡献 |
| [`real_data/`](real_data/README.md) | 真实数据（ETTh1、Weather、Electricity）：在 iTransformer / S-Mamba 式骨架上检验稀疏变量混合、身份嵌入、变量顺序敏感性和顺序鲁棒训练 | 稳定有效的只有变量身份嵌入（多变量数据上 −3% ~ −5.5%）；稀疏混合没有迁移到真实数据；双向 Mamba 对变量顺序敏感，但强迫顺序无关反而变差 |

所有实验都在 CPU 上以受控预算运行，每种配置 3 个种子、按种子配对比较；具体设置、局限和复现命令见各目录的 README。
